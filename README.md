# Icepear · Android 2.3.0

一款完全离线的私人陪伴与聊天模拟应用。界面层使用原生 WebView 承载 HTML/CSS/JavaScript，Android 外壳负责文件选择、备份导出、系统返回键和安全的本地存储。

## 构建环境

- JDK 17 或更高版本
- Android SDK 35
- Android Build Tools 35.0.0
- Gradle 8.10.2（已包含 Wrapper）

设置 `ANDROID_HOME` 后执行：

```powershell
.\gradlew.bat assembleDebug
.\gradlew.bat assembleRelease
```

`assembleRelease` 默认生成未签名 APK。正式分发时请使用随交付包保存的 release keystore 进行 `zipalign` 与 `apksigner` 签名。

## 主要修复

- 小卖铺支持新建、改名、删除任意商品分组；点进分组只显示本组商品，商品列表可折叠，添加商品入口移动到页面底部并改为应用内表单。
- 朋友圈支持发布自己的动态、删除、评论与点赞，修复自定义头像裁切；对方的自动评论只会使用现有字卡。
- 引用消息可点按跳回原消息并高亮；头像双击只触发拍一拍，消息双击只打开消息操作，支持拍一拍自己。
- 表情包管理和聊天表情面板支持折叠；Emoji 删除按钮点按后才显示在右上角。
- 夜间模式覆盖状态栏、顶栏、内容区、输入栏与底部导航，不再只变暗中间区域。
- 红包和转账在对方余额不足时的兜底文案可分别自定义，留空即可关闭；普通文本回复不再绕过字卡库生成写死文案。
- 消息长按菜单改为紧贴消息气泡的深色双排宫格，恢复复制、转发、收藏、撤回/删除、多选、引用、提醒、翻译、搜一搜和连续朗读。
- 视频通话悬浮窗贴边后会完全移出屏幕，仅保留窄型展开把手；同时清除旧补丁遗留的冲突触摸监听。
- Emoji 和图片表情的删除按钮默认隐藏，点按单个项目后才在右上角显示 20×20 小按钮。
- 信件、角色、纪念日、评论和字卡导入使用应用内弹窗，不再出现 `file://` 网页原生输入框。
- 恢复“设置 → 数据”的永久补丁系统，加入补丁导出、99 条容量和启动失败安全模式。
- 恢复“设置 → 样式”的全局美化编辑器，可统一页面、卡片、顶栏、底栏与强调色，并支持受限自定义 CSS。
- 消息提示音支持从本地添加、试听、选择和删除自定义音频，音频放入 IndexedDB 避免占满设置存储。
- 聊天词云改为 900×1120 高清纸感排版，采用防重叠布局并显示关键词数量。
- 视频通话小窗可拖动，靠近左右边缘会自动缩入屏幕，点按露出的边缘即可展开。
- 首次升级后默认让每条消息显示时间戳和已读/未读，仍可在消息显示设置中调整。
- 应用显示名称更改为 Icepear，并使用用户提供的蓝色小猫图片作为方形、圆形与自适应图标。
- 修复部分 Android 8–10 或定制 ROM 启动时加载 Android 30 专用系统栏类型导致的闪退。
- 系统安全区改用 Android 8 即支持的兼容接口；若系统 WebView 缺失，会显示处理提示而不是直接退出。
- 适配 Android 15 强制边到边显示，系统状态栏和手势导航栏不再遮住应用内容。
- 加入由图像生成工具制作并本地压缩的日夜花笺壁纸，浅色/深色模式自动切换。
- 修复“拍一拍”文案多出“了他”及快速双击重复发送的问题。
- 统一交易卡片、顶栏、表单和底部导航的布局、截断与触控反馈。
- 恢复原文件的中文乱码；补丁入口现在带有明确风险提示、自动快照和启动安全模式。
- 修复红包、转账、礼物的重复入账与退还结算错误。
- 自动回复绑定到发起会话的角色，避免切换角色后消息串线。
- 备份时展开 IndexedDB 图片引用，恢复后不再丢失头像、壁纸和表情。
- 修复视频小窗点击“挂断”后又恢复全屏的问题。
- 修复音量无法保存为 0、气泡圆角仅预览不生效、卡片主题选中态错误。
- 修复过滤列表索引、消息自动滚动、动态和周报跨角色混用等问题。
- 新增 Android 系统返回、文件选择与下载桥接，以及独立的 release 签名。

## 数据与隐私

聊天与设置存储在应用 WebView 的本地数据空间，不上传服务器。`INTERNET` 权限只用于显示用户主动添加的 HTTPS 图片地址；应用本身不依赖网络服务。
